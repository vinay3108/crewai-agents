#+ CrewAI Learn

Simple learning workspace for experimenting with CrewAI agents and tools.

## Contents

- `emailagent.ipynb`: Basic email assistant example.
- `emailagentwithtool.ipynb`: Email assistant with a custom tool.
- `main.py`: Optional script entry point.

## Quick Start

1. Create and activate a virtual environment.
2. Install dependencies.
3. Open the notebooks and run the cells.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Notes

- The notebooks expect environment variables from a `.env` file.
- Run notebook cells in order so shared variables are available.
